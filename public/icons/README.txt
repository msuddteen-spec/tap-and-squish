PWA icon assets included in this folder:

- icon-192.png (192x192, purpose any)
- icon-512.png (512x512, purpose any)
- icon-maskable-192.png (192x192, purpose maskable)
- icon-maskable-512.png (512x512, purpose maskable)
- apple-touch-icon.png (180x180)
- favicon-32.png (32x32)
- favicon-16.png (16x16)
- favicon.ico

The PNG/ICO files are generated from icon-source.svg and are valid image files.
Replace icon-source.svg and regenerate these files if the app branding changes.
